# اتاق صفر | ROOM 0

این پروژه یک پایه‌ی واقعی برای Mini App تلگرام به نام «اتاق صفر | ROOM 0» است. هدف، ساخت یک بازی استنتاجی چندنفره با میزهای رزرو، نقش‌های مخفی، بازی‌های زنده، تماشاچی‌ها، پنل مدیریت، و معماری قابل توسعه است.

## ساختار پروژه

- `backend/` — سرویس FastAPI، احراز هویت، موتور بازی، مدل‌های دیتابیس، و API
- `frontend/` — رابط React + TypeScript + Vite + Tailwind
- `deploy/` — فایل‌های استقرار و تنظیمات VPS
- `scripts/` — اسکریپت‌های پشتیبان‌گیری و مدیریت
- `docs/` — مستندات و نقشه راه
- `docker-compose.yml` — اجرای هم‌زمان سرویس‌ها
- `.env.example` — نمونه تنظیمات محیطی
- `README.md` — راهنمای اصلی فارسی

## معماری کلی

- احراز هویت تنها در بک‌اند با اعتبارسنجی `initData` تلگرام انجام می‌شود.
- منطق بازی و قانون برد در سرور اجرا می‌شود.
- فرانت‌اند فقط نماینده‌ی وضعیت معتبر سرور است.
- داده‌های خصوصی نقش‌ها در API عمومی منتشر نمی‌شوند.
- WebSocket/رویدادهای لحظه‌ای برای وضعیت میز و بازی استفاده می‌شوند.
- LiveKit در نسخه‌ی اولیه به‌صورت اختیاری و با تنظیمات واقعی فعال می‌شود.

## فازهای اجرا

1. زیرساخت و احراز هویت
2. رابط کاربری و فهرست میزها
3. رزرو، تأیید حضور و انتظار
4. موتور بازی و قانون برد
5. رویدادهای زنده و بازیابی وضعیت
6. صدا و تماشاچی
7. پنل مدیریت
8. امنیت، تست‌ها و استقرار
9. تست یکپارچه و مستندات فارسی

## اجرای محلی

```bash
cp .env.example .env
python -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cd frontend && npm install
```

### اجرای بک‌اند

```bash
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### اجرای فرانت‌اند

```bash
cd frontend
npm run dev -- --host 0.0.0.0
```

## اجرای Docker

```bash
docker compose up --build
```

## تست‌ها

```bash
cd backend
pytest -q
```

## نکته مهم

این پروژه در سطح پایه‌ی واقعی و قابل اجرا ساخته شده است. بخش‌های پیشرفته‌تر مانند LiveKit، پنل مدیریتی کامل، سیستم صدا و موتور بازی کامل‌تر در فازهای بعدی به‌صورت واقعی و دقیق توسعه خواهند یافت. هیچ اطلاعات حساس یا توکن واقعی در سورس قرار داده نشده است.
